# SAS.Planet Web & Python GIS Studio

واجهة خرائط عربية وإنجليزية، مع أدوات اختيار المناطق، التخزين، دمج البلاطات، العلامات والتحليل الطبوغرافي.

## نسخة ويندوز المحمولة دون تثبيت

الحزمة الجاهزة: releases/SAS.Planet-Portable-Windows-x64-v1.5.zip.

فك ضغط الملف بالكامل في مجلد قابل للكتابة؛ ينشئ التحديث مجلداً مستقلاً SASPlanet-Portable-v1.5 للحفاظ على النسخة السابقة، ثم شغّل SAS.Planet Portable.exe. انقل المجلد كاملاً عند استخدام USB أو جهاز آخر. Python وNode.js وPillow مضمنة؛ لا تحتاج تثبيتها. النسخة تدعم Windows 10 الحديث وWindows 11 بنظام x64، وتستخدم .NET Framework 4.8 المدمج وEdge أو Chrome الموجود لفتح نافذة التطبيق، أو المتصفح الافتراضي عند غيابهما.

أغلق التشغيل من أيقونة البرنامج بجانب الساعة أو عبر Stop.cmd. تُحفظ الإعدادات في data/settings.json، وملف المتصفح في data/browser، وبلاطات الخرائط في cache_gmt بجانب ملف EXE، وبيانات الارتفاع في app/cache/terrain، والصادرات في app/public/exports. الواجهة والتحليل يعملان محلياً؛ تنزيل خرائط أو ارتفاعات غير مخزنة يتطلب الإنترنت. يمكن استيراد ملفات HGT للتحليل دون اتصال.

لإعادة بناء الحزمة على ويندوز: npm ci ثم npm run build:portable. تُنزّل نسخ التشغيل الرسمية مع التحقق من SHA256، ويُضمّن المصدر والتراخيص دون ملفات .env أو بيانات المستخدم. أمر التحقق من ZIP: python tests/smoke_portable.py. يتطلب البناء اتصالاً بالإنترنت وPython 3.10+، ولا يحتاج المستخدم النهائي هذه الأدوات.

## التشغيل من المصدر

المتطلبات: Node.js، وPython 3.10 أو أحدث.

1. ثبّت مكتبات الواجهة: npm install
2. ثبّت قارئ صور بيانات الارتفاع: python -m pip install -r requirements.txt
3. شغّل البرنامج: npm run dev
4. افتح http://localhost:3000

لا يلزم مفتاح Gemini لاستخدام الخرائط وخطوط التسوية.

## كاش الخرائط مثل SAS.Planet

تُحفظ الخرائط المعروضة والتنزيلات الافتراضية في cache_gmt بجانب ملف EXE في النسخة المحمولة، وفي مجلد المشروع عند التشغيل من المصدر. البنية هي Global Mapper / GM1 الأصلية: cache_gmt/المصدر/z{XYZ zoom}/Y/X.jpg، مع الامتداد الحقيقي للصورة. يطابق الترتيب u_TileFileNameGM1.pas داخل أرشيف SAS.Planet المرفق.

أسماء المجلدات: Google Satellite = sat، تسميات Google = Both، خرائط Google = map، تضاريس Google = land، Esri = ArcGIS.Imagery، OSM = osmmapMapnik، Yandex = yasat. Google Hybrid المدمج يستخدم Google.Hybrid حتى لا يختلط بكاش التسميات Both.

يمكن نسخ مجلدات المصادر من cache_gmt في SAS.Planet إلى هذا المجلد؛ اختر المصدر ومستوى التكبير المطابقين. لا تُضمّن الخرائط الخاصة بالمستخدم في ملف ZIP الموزع. افتح «إدارة الكاش» لفتح المجلد ونسخ المسار ومشاهدة عدد البلاطات لكل مصدر. يقرأ وضع عدم الاتصال الملفات المحلية دون تنزيل بلاطات ناقصة. يبقى كاش الارتفاعات في app/cache/terrain.

تُقرأ بنية SAS الأصلية أيضاً عند استيرادها، مع z أكبر بواحد من XYZ. وتُستعاد بلاطات الإصدار السابق من app/cache إلى GM1 عند استخدامها دون حذف الأصل. تُنسخ البلاطات المتاحة في كاش المتصفح القديم إلى القرص عند استعادتها. صيغ SAS وOSM وTMS وMBTiles تبقى متاحة ضمن خيارات تنزيل المنطقة.

## خطوط التسوية الصحيحة

- حدّد منطقة على الخريطة، أو افتح أداة «خطوط التسوية» لتستخدم المشهد الحالي.
- المصدر الافتراضي Mapzen Terrain Tiles، بترميز Terrarium. يتم تنزيل البيانات الفعلية وحفظها داخل cache/terrain/terrarium.
- اختر الفاصل الرأسي وحجم شبكة الاستخراج، ثم اضغط «توليد وعرض خطوط التسوية».
- يظهر مصدر البيانات وتباعد عينات الشبكة وحجم بكسل المصدر التقريبي في النتيجة وفي GeoJSON. تكبير الشبكة لا يحسن دقة المصدر الأصلية. للمناطق الواسعة استخدم فاصلاً أكبر أو منطقة أصغر.
- لا تُستخدم معادلات ارتفاع اصطناعية أو قيم بديلة عند فشل التنزيل.
- تُوصل مقاطع الخط عند حدود خلايا الشبكة، مع معالجة فرعي الحالات السرجية واستبعاد خلايا NoData.
- إخفاء المستوى صفر والارتفاعات السالبة مفعّل افتراضياً. ألغِ هذا الخيار لدراسة المنخفضات الواقعة تحت مستوى البحر أو الأعماق.
- من الشريط الإضافي يمكنك إخفاء الخطوط، عرض الخطوط الرئيسية فقط، ضبط العتامة، أو إزالة الطبقة.
- يدعم الاستوديو تصدير GeoJSON، وإنشاء BMP مع BPW بإحداثيات EPSG:4326. ملف BPW يصف مواضع مراكز البكسلات؛ حدّد EPSG:4326 عند الاستيراد في برنامج GIS.

## SRTM دون إنترنت

اختر «استيراد ملفات SRTM (.hgt)». يجب أن تكون الملفات الأصلية غير المضغوطة بأسماء مثل N36E003.hgt، بحجم 1201×1201 أو 3601×3601 عينة signed int16 big-endian. تُحفظ الملفات داخل cache/terrain/srtm. استورد جميع البلاطات التي تغطي المنطقة ثم اختر مصدر SRTM المحلي. لا تُملأ البيانات الناقصة بارتفاع صفر. وضع عدم الاتصال يمنع تنزيل بلاطات الارتفاع ويعتمد على البيانات المحفوظة أو الملفات المحلية.

## اختيار نظام الإحداثيات

من إعدادات ← الإحداثيات ← نظام عرض الإحداثيات اختر UTM — Nord Sahara 1959، ثم اختر تلقائي أو المنطقة 29N أو 30N أو 31N أو 32N واضغط حفظ وتطبيق. يظهر Easting وNorthing بالمتر ورمز EPSG في شريط الحالة، ويُحفظ الاختيار في النسخة المحمولة. اختيار المنطقة نفسه يُستخدم افتراضياً عند فتح أداة الانتقال إلى إحداثيات Nord Sahara.

المناطق هي EPSG:30729–30732، بمرجع Nord Sahara 1959 وإهليلج Clarke 1880 (RGS). تحويل WGS84 يستخدم EPSG:1253، بدقة منشورة تقريبية 44 م. لا تُقحم مواقع خارج مجال المرجع في منطقة جزائرية افتراضية. هذا اختيار للعرض، ولا يعيد إسقاط ملفات ArcGIS التي تصدرها أداة التضاريس.

المصدر المرجعي للمعلمات: [قاعدة PROJ للتحويلات](https://github.com/OSGeo/PROJ/blob/master/data/sql/helmert_transformation.sql)، [تعريف أنظمة الإسقاط](https://github.com/OSGeo/PROJ/blob/master/data/sql/projected_crs.sql)، [الإهليلجات](https://github.com/OSGeo/PROJ/blob/master/data/sql/ellipsoid.sql). توجد نقاط تحقق من PROJ / pyproj في tests/fixtures/nord_sahara_reference.json، وتُختبر الواجهة ومحرك Python على النقاط نفسها.

## تحليل التضاريس والتصدير إلى ArcGIS

1. حدّد المنطقة أو انتقل إليها، ثم افتح «تحليل ← تحليل التضاريس و ArcGIS».
2. اختر مصدر الارتفاعات وحجم الشبكة والفاصل الكنتوري. فعّل الجريان إذا احتجت ملء المنخفضات واتجاه D8 والتراكم.
3. اضغط «تحليل وتجهيز حزمة ArcGIS»، ثم عاين الطبقات أو اعرضها فوق الخريطة.
4. في تبويب «التصدير إلى ArcGIS» نزّل ZIP وفكّه في مجلد واحد.
5. داخل ArcGIS Pro أو ArcMap اختر Add Data وأضف relief.tif و contours.shp. أضف dem.tif للارتفاعات الرقمية.

الحزمة تحتوي على GeoTIFF Float32 لنموذج الارتفاعات والانحدار واتجاه السفوح والظلال وTPI والخشونة. مع تفعيل الجريان تشمل أيضاً filled_dem وfill_depth وflow_direction وflow_accumulation. تشمل الخريطة الملونة GeoTIFF RGBA وخطوط كنتور Shapefile PolyLineZ مع ELEV_M وINDEX_LN وINTERVAL، إضافة إلى GeoJSON وESRI ASCII ودليل وmetadata.json وسكربت ArcGIS Pro اختياري.

الإسناد الأفقي WGS84 / EPSG:4326 بالدرجات، والارتفاعات بالمتر. لإحداثيات UTM يجب إعادة الإسقاط فعلياً باستخدام Project Raster؛ لا تستعمل Define Projection لتسمية البيانات الجغرافية UTM. لا يجري تحويل مستقل للمرجع الرأسي.

المشتقات تستخدم Horn 3×3 ومسافات أرضية حسب خط العرض على WGS84. الحواف والجوار الناقص NoData، واتجاه السفوح للأسطح المستوية -1. المبالغة الرأسية تطبق على الظلال فقط. TPI هو ارتفاع المركز ناقص متوسط الجيران الثمانية؛ الخشونة فرق أعلى وأدنى ارتفاع في 3×3.

الجريان يستخدم Priority-Flood لملء المنخفضات ثم D8 لأشد انحدار. تُوجه المناطق المستوية على شجرة الملء لمنع الدورات. التراكم هو عدد الخلايا المساهمة دون الخلية نفسها، ولا يمثل تصريفاً مائياً أو عمق فيضان. حدود المنطقة وحدود NoData منافذ خارجية؛ التحليل محلي إلى نطاق الاستخراج.

تحافظ الرسترات وخطوط الكنتور على نفس مصدر الارتفاع وشبكة العينات. قد يمتد الحد الشرقي أو الجنوبي بأقل من بكسل لمحاذاة خلايا مربعة بالدرجات؛ تُسجل الحدود الفعلية في metadata.json.

مراجع التنفيذ:

- [Esri: طريقة حساب الانحدار](https://pro.arcgis.com/en/pro-app/3.1/tool-reference/3d-analyst/how-slope-works.htm)
- [Barnes et al.: Priority-Flood](https://rbarnes.org/sci/2014_depressions.pdf)
- [Esri: اتجاه الجريان D8](https://doc.arcgis.com/en/arcgis-online/analyze/how-flow-direction-works.htm)
- [Esri: مواصفات Shapefile](https://content.esri.com/support/whitepapers/ao_/shapefile.pdf)
- [GDAL: GeoTIFF](https://gdal.org/en/stable/drivers/raster/gtiff.html)

تحقق إضافي بعد تشغيل الخادم وتنزيل بيانات منطقة بجاية المرجعية: python tests/smoke_arcgis_api.py

## GIS Studio v1.3

زر **أدوات GIS والمباني** يفتح: رسم المباني وضبط الزوايا وتعديل الرؤوس، اقتراح سقف من صورة الكاش بخوارزمية GrabCut، استيراد وقص ودمج DEM GeoTIFF، الأحواض والمجاري D8، الرؤية على كامل المنطقة، إسناد الصور بنقاط تحكم، خرائط PDF A4/A3، GeoPackage، وتغطية الكاش وطابور تنزيل دائم.

قياس المسافة يستخدم GeographicLib/Karney على WGS84 ويعرض النتيجة مباشرة. أنْهِ بالنقر المزدوج أو Enter أو زر إنهاء، وتراجع بـBackspace.

من نافذة **تحليل التضاريس والتصدير إلى ArcGIS** اختر إسقاط الناتج: WGS84، UTM المحلي، أو Nord Sahara 1959 / UTM 29N–32N. تتم إعادة إسقاط البكسلات وإحداثيات SHP فعلياً؛ GeoJSON ومعاينات PNG تبقى WGS84. تحويل Nord Sahara يستخدم EPSG:1253 بدقة منشورة 44 متراً، ولا يحل محل شبكة تحويل مساحية محلية.

للمباني: كبّر للصورة، ارسم مضلعاً، انقر مرتين، اضغط ضبط زوايا الرسم، حرّك الرؤوس عند الحاجة ثم اعتمد النتيجة. للاقتراح من الصورة حدد مستطيلاً حول سقف واحد مع هامش خلفية، ويجب أن تكون صور المصدر/التكبير موجودة في cache_gmt. الاقتراح حد سقف يحتاج مراجعة؛ لا يدّعي تحديد البصمة الأرضية آلياً أو دقة مساحية. لا تُرسل الصور إلى خدمة خارجية.

خرائط PDF تتضمن شبكة UTM وسهم شمال الشبكة ومقياساً ومفتاحاً وخطوط تسوية معنونة. اطبع بالحجم الأصلي. أدخل صفراً للمقياس لملاءمة المنطقة، أو مقام المقياس المطلوب. بيانات DEM يجب أن تكون ارتفاعات بالمتر مع CRS صحيح؛ لا تُحوَّل المراجع الرأسية تلقائياً. الرؤية تعتمد على سطح الارتفاع، والحوض محدود بالمنطقة المستخرجة؛ عتبة المجاري عدد خلايا مساهمة وليست تصريف مياه.

الإسناد يستخدم Affine least squares و3 نقاط غير مستقيمة على الأقل. تقرير RMSE أخطاء ملاءمة وليس دقة مستقلة؛ ثلاث نقاط قد تعطي خطأ صفرياً رغم خطأ الإحداثيات.

الكاش: طابور GM1 محفوظ في app/cache/jobs/cache-jobs.json في النسخة المحمولة، ويعود متوقفاً بعد إعادة التشغيل. الفحص يكشف الصور التالفة دون حذفها، والإصلاح يستبدل البلاطة فقط بعد التحقق من الصورة الجديدة. GeoPackage يصدّر العلامات والبلاطات الموجودة؛ لا ينزل الناقص أثناء التصدير. اختر المصدر المطابق قبل استيراد بلاطات الحزمة إلى الكاش.

النسخة المحمولة تشمل مكتبات GDAL/PROJ/OpenCV/NumPy/Shapely/ReportLab/Pillow والخط العربي المرخص OFL. قفل الحزم وروابطها وبصماتها في scripts/portable/gis-runtime-lock.json. للتطوير، ثبّت requirements-gis.txt أو جهّز build/gis-python؛ البناء المحمول يستخدم العجلات المقفلة.

## 3D terrain viewer — v1.4

زر **عرض الأرض 3D** يفتح مشهداً محلياً للتضاريس بصور مصدر الخريطة فوق DEM حقيقي. يدعم التدوير والتقريب والتحريك وتضخيم الارتفاعات وإظهار المباني المرسومة وحفظ لقطة PNG. اختر المنطقة ومصدر DEM (Mapzen أو SRTM أو GeoTIFF محلي)، وحدد مستوى تكبير صور الكاش، ثم أنشئ المشهد. في وضع عدم الاتصال تُستخدم البيانات المخزنة فقط؛ الصور الناقصة رمادية وارتفاعات NoData تظل فراغات.

يستخدم المشهد إسقاط UTM المحلي ومسافات وارتفاعات مترية، مع UV مشتقة من Web Mercator لضبط محاذاة صور البلاطات. المشهد المحلي بين 10 م و50 كم، وتتحول المشاهد الأوسع إلى منطقة نحو 5 كم حول المركز. الحد الأقصى 64 بلاطة صورة لكل إنشاء. دقة الشبكة لا تعني زيادة دقة DEM الأصلي، وتعرض الواجهة دقة المصدر.

تُعرض المباني المرسومة كمجسمات ذات سقف مستوٍ بارتفاع تقديري يحدده المستخدم. لا تستنتج هذه الأداة ارتفاع المبنى أو تفاصيل الواجهة من صورة القمر الصناعي، ولا تتضمن بيانات Google Photorealistic 3D أو خدمة مدفوعة. اتجاه الشمال هو شمال شبكة UTM.


## إضافات النسخة المحمولة 1.5
افتح «الأدوات الاحترافية» فوق الخريطة لإدارة المشاريع، والتحرير المتجهي مع التقاط الرؤوس والحواف والتراجع والإعادة، وفحص التداخلات والفراغات، وتقارير جودة DEM ونقاط التحقق المستقلة. تُحفظ المشاريع محلياً في app/cache/projects مع نسخ احتياطية، وتُصدّر بصيغة .sasgis مع ملفات التحليل وDEM الذي تختاره. الكاش لا يُضمّن في المشروع.

يدعم فهرس الأوراق استيراد GeoJSON مع مضلعات الأوراق وحقول الرقم والاسم والإصدار والسنة، والجهة الناشرة ومصدر الوثيقة وCRS. لا يُرفق فهرس INCT رسمي: تبقى الشبكة المولدة مميزة عنه، وأصالة الملفات المستوردة مسؤولية مصدرها. بعد الاستيراد يمكن البحث بالاسم والرقم والإصدار واختيار الورقة على الخريطة.

في تبويب الأطلس اختر حتى 12 ورقة لإنشاء PDF A1 بمقياس 1:25000، وصفحات تركيب A4/A3 بتداخل قابل للتعديل. اطبع بالحجم الأصلي 100% دون ملاءمة الصفحة. حافظ على مرجع المصدر الأفقي والرأسي؛ تقرير RMSE لا يُعد شهادة دقة مساحية.

في عارض الأرض 3D، افتح التصدير للطباعة وفعّل التقسيم حسب حجم الطابعة. تُصدر قطع STL و3MF مغلقة، وخطة تركيب ودبابيس منفصلة مع ثقوب محاذاة داخل القاعدة. يلزم سمك قاعدة مناسب، وتُرفض البيانات ذات الارتفاعات المفقودة. افحص الخلوص والتفاصيل في برنامج التقطيع قبل الطباعة؛ لا يُنشأ G-code.


## الخرائط والعمل الميداني داخل 1.5
افتح «الأدوات الاحترافية ← الخرائط والعمل الميداني». تتضمن:
- عرض GeoTIFF محلي مسند في مدير طبقات، وترتيب الطبقات والشفافية وإظهار الرسومات؛ تُحفظ الطبقات والصور مع المشروع وتُرفق أصولها في .sasgis.
- GPX مع نقاط ومسارات وطرق، ووقت وارتفاع وHDOP ومقاطع منفصلة. التحليل لا يصل فجوات التسجيل؛ التقسيم والدمج وتنعيم الارتفاعات وفصل القفزات وإسناد DEM تنشئ نسخاً جديدة.
- GPS حقيقي عبر Web Serial في Edge/Chrome. اختر جهاز NMEA 0183 وسرعة المنفذ؛ تظهر جودة GGA وHDOP، ويدعم RMC وقت الجهاز والسرعة. السجل الميداني يتوقف عن إضافة نقاط صالحة عند فقد التثبيت. يبقى المحاكي أداة منفصلة.
- إضافة WMS 1.1.1 بإسقاط EPSG:3857 وWMTS KVP بشبكة Web Mercator XYZ ذات بلاطات 256. أدخل اسم الطبقة وTileMatrixSet وبادئة رقم المستوى عند الحاجة؛ الخدمات الخارجية تُوقف في وضع عدم الاتصال.
- صور EXIF GPS واتجاه التصوير؛ يمكن إدخال الموقع يدوياً. تُنشأ معاينة محلية للصورة دون تعديل الأصل.
- أقصر مسار Dijkstra على شبكة طرق GeoJSON محلية؛ تُحترم اتجاهات one-way للسيارة والدراجة وقيود access/foot/bicycle/motor_vehicle الأساسية. يلزم اشتراك الرؤوس عند التقاطعات. لا يشمل حركة المرور أو قيود الانعطاف أو تحديث الشبكة.
- مسارات تغطية متوازية مقصوصة بالحدود والثقوب؛ لا تُخطط وصلات الانتقال بين المسارات أو تفادي العوائق.
- شبكة UTM مترية مع EPSG وتباعد قابل للتحديد، وتحويل CSV دفعة واحدة مع إبقاء الصفوف ذات الأخطاء وتقرير مرجع التحويل. Nord Sahara يستخدم EPSG:1253 الأفقي بدقة منشورة 44 م؛ لا يُحوّل المرجع الرأسي.
- تصدير Garmin KMZ بقطع JPEG لا تتجاوز 1024 بكسل، أو ZIP للهواتف يضم GeoTIFF وGPX وKML وبلاطات. تُعاد عينات الصور من Mercator إلى الإحداثيات الجغرافية فعلياً قبل إنشاء LatLonBox. تحقّق من حدود جهاز Garmin؛ ZIP ليس قاعدة OruxMaps خاصة.

التحديثات الصغيرة تستهدف مجلد وحزمة 1.5 نفسيهما. لتحديث هذه الإضافات من المصدر: python scripts/portable/update_existing.py. لا يُعاد جمع الكاش أو إعدادات المستخدم في ملف التوزيع. أغلق البرنامج وأعد فتحه بعد تحديث الخادم.


## Sahara GIS — صحارى GIS (نفس الإصدار 1.5)
شغّل Sahara GIS.exe. الواجهة تفتح في نافذة سطح مكتب مستقلة بمحرك Electron المضمن، دون الاعتماد على Edge أو Chrome في الجهاز الآخر. أغلق التشغيل السابق من أيقونة الساعة قبل أول تشغيل بعد التحديث.
عند نقل نسختك انسخ المجلد كله، وخاصة cache_gmt للخرائط وdata للإعدادات وapp/cache للارتفاعات والمشاريع. ملف ZIP النظيفة لا يضم الخرائط الشخصية.
«إدارة الكاش» يعرض المسار المطلق، ويفتحه في مستكشف ويندوز، ويتيح اختيار مجلد موجود ونسخ الكاش إلى وسيط النقل. المسار المختار داخل مجلد البرنامج يُحفظ نسبياً ليستمر بعد نقل المجلد. إن غاب مسار خارجي في الجهاز الآخر، تظهر رسالة ويُستخدم cache_gmt بجانب التطبيق.
بقيت تسمية مجلد التوزيع وملف ZIP القديمة للتوافق مع تحديث 1.5 الموجود؛ اسم التطبيق والأيقونة والمشغّل الجديد Sahara GIS.

### Offline 3D terrain in Sahara GIS 1.5
Map images under cache_gmt do not include numerical elevation data. In the 3D viewer, use Save region elevations for offline use while online, then Check offline elevation readiness. Alternatively import uncompressed N36E003.hgt-style SRTM files directly in the viewer and choose SRTM HGT, or select a covering local GeoTIFF DEM. Keep app/cache/terrain when moving the portable folder. The prepare action verifies the selected scene bounds/detail; it does not download all image zoom levels. Missing elevation samples remain holes.
